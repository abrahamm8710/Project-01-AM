# Project Reflection

## Decisions
Some of the most important decisions I made was to make it sure to avoid making my portfolio website into a simple/static site that lacks interactive features. I didn't want my website as simple or basic, I wanted to make sure it was interactive which it has. I didn't want vistors to view my site as something basic with no low effort. I want vistors to see that I put effort into it. Making sure I used more than one color was important decision because I didn't want my website to only have one main color, the website wouldn't stand out.
## What worked
What has worked for me was being able to turn my skills, hobbies, and experience text and put them into card like format with interactively. This has worked for me because I didn't want to only use text to show of my skills, hobbies, etc, I wanted to put them inside a card to make it stand out more, I lncluded images and descriptions for each card as well added a color to fill the inside of the card. If I don't do this, my site wouldn't stand out and all you would see is just pure text with no formating. What also worked was using Javascript for my loading screen animation. I wanted my site to feel like a video game in some way whenever a game is loading on a screen so I did that for this portfolio website. 
## What I would do differently
If I were to start over, what I would do differently is to find more ways to implement Javascript more. I say this because I was able to use Javascript for one thing which was for my loading screen. I wanted to Javascript for other features I planned to add to my site, such as adding a 2d or 3d drivable car on my site if users were to get bored. I struggled to get one working and didn't have time to get going on that, so I had to ditch the idea. I would also do differently is add more content to my home page, because it feels empty and lacking content, the only thing that was on there was the my name and picture with a short bio within a blue card, everything outside of it was empty, this is something I wished I could have done differently. 
## What I Learned
What i have learned is that creating a website using HTML and CSS code takes time and effort to make a functioning site. There is a lot that goes into your mind when creating a website, such as format, structure, and how much content to put on there, and more. Creating a website is like taking care of a plant or pet you got to take time and put effort into both things. When using AI tools such Visual Studio Copilot and ChatGPT, you have to be very specific to the AI assistant on what you want exactly, it is helpful in a lot of things regarding coding, structure, but it can lack understanding, if you don't specify exactly what you want. What I learned about myself when creating this website is that this has shown me that I am capable of creating websites once I learn more on how to do them consistently. There is a lot for me to learn when creating websites from code, but I am confident that I will get better from here.
